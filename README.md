## Deployment

This site is deployed on GitHub Pages at: https://tanky0.github.io/

To update:
1. Edit files locally
2. Commit changes: `git add .` && `git commit -m "Description"`
3. Push: `git push`
4. Wait 1-2 minutes for changes to appear
