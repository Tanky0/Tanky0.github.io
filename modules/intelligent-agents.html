Module Overview

Intelligent Agents examines the design and implementation of autonomous agents: systems that perceive an environment, reason about it, and act within it to pursue objectives. The module covers agent architectures and rational decision-making, agent communication languages and dialogue, parsing and knowledge exchange between agents, multi-agent coordination, and deep learning applied to agent behaviour.

Core reading is drawn from Russell and Norvig's Artificial Intelligence: A Modern Approach and Wooldridge's An Introduction to MultiAgent Systems. The module builds directly on the AI foundations established in Understanding Artificial Intelligence and on the probabilistic reasoning developed in Numerical Analysis. It is the first module of the programme assessed on work produced as part of a development team.

Module Aims and Learning Outcomes

This module aims to instil amongst students:

  • An understanding of the motivations for, and appropriate use of, agent-based computing.
  • An understanding of the main agent models in use today and their grounding in artificial intelligence research.
  • The knowledge and skills required to develop, deploy and evaluate the tools and techniques of intelligent systems to solve real-world problems.
  • An understanding of contemporary research issues in the area of intelligent agent systems.

On completion of this module, students will be able to:

  1. Identify and critically analyse agent-based systems, differentiating between architectures and approaches.
  2. Apply and critically evaluate intelligent agent techniques to real-world problems, particularly where technical risk and uncertainty is involved.
  3. Deploy critically appropriate software tools and skills for the design and implementation of an agent-based system, bearing in mind applicable legal, social, ethical and professional issues.
  4. Systematically develop and implement the skills required to be an effective member of a development team in a virtual professional environment, adopting real-life perspectives on team roles and organisation.

Individual Project: Presentation

Unit 11 · Deadline: 23:55, Monday 12 October 2026

Brief Description: Implement, individually, the LLM-powered planning agent the group designed in Unit 6, with evidence of development progress across the module, testing activities and any remediation undertaken. Submitted as source code and documentation, testing outputs, a README, and a presentation of up to ten slides with a narration transcript. The Unit 6 design is not a fixed specification: justified and documented changes are acceptable where technical constraints require them, provided the system remains an agent that takes a goal, plans a sequence of actions, retrieves and processes data, and produces a meaningful output.

Submission: In development since 26 August 2026. Two cooperating agents over a schema-validated JSON buffer, with deduplication, validation and storage deliberately outside the model. Built so far: the requirements table, the shared HTTP layer, four source adapters for PubMed, PubMed Central, Semantic Scholar and Crossref, the record formats both agents exchange, a hundred passing tests, and a hundred abstracts screened by hand to measure recall against. Since 1 September the two agents are connected into a single run, with the hand-over between them covered by integration tests. Neither is finished, and the interface, the storage layer and the functional test run remain ahead, with that run planned for 17 to 18 September.

Reflective Piece

Covers all four learning outcomes. This is the only component of the e-portfolio with a strict word limit, so it is written to the published grading criteria rather than assembled from notes at the end.

The top band of those criteria, Reflective Review, requires more than a description of what happened. It asks for analysis of the choices made, multiple perspectives on them, critique of the artefacts produced, engagement with and critique of relevant literature, and an action plan that follows from all of it. Structure follows the three W's: What? (description, the shortest part), So What? (interpretation and analysis), What Next? (outcome and forward actions).
